Manim, for this project

How the community edition of manim (manim 0.22) is structured, where its files come from and go, and how it connects to blur.py. The two demo scenes in this folder are the running examples.

1. The mental model

A manim video is a Python class. You never draw frames yourself. You build objects, then tell manim how they change over time, and it renders every frame through Cairo and pipes the frames into ffmpeg.

Scene subclass→construct()→ Mobjects→self.play(Animation)→ frames→ffmpeg→.mp4
ConceptWhat it is
SceneOne video clip. Each Scene subclass in a file renders to its own mp4. Use one file per graphic, with one or more scenes in it.
MobjectAnything drawable: Text, MathTex, Arrow, Matrix, Axes, ImageMobject. Group/VGroup nest them. Positioning is relative: .next_to(), .arrange(), .to_edge(). The frame is 14.2 × 8 units.
AnimationA change over time, passed to self.play(): FadeIn, Write, Transform, GrowArrow, or mob.animate.<method>() for any method call. self.add() shows something instantly, and self.wait() holds the frame.
ValueTrackerAn invisible number you can animate. It's the knob, for example σ.
UpdaterA function run on a mobject every frame. always_redraw(fn) rebuilds a mobject each frame. Together with a tracker this gives you live parameters: this is how the blur gets into the video.

2. Demo: the Gaussian sweep

The whole connection to the GPU is the updater:

sigma = ValueTracker(0.5)

def render():
    result = blur.gaussian(source, sigma.get_value(), radius=RADIUS, separable=True)
    stats["ms"] = result.gpu_ms
    return blur.to_uint8(result.image)         # ImageMobject wants uint8

image = ImageMobject(render())
image.add_updater(lambda m: setattr(m, "pixel_array", render()))  # every frame

self.play(sigma.animate.set_value(12.0), run_time=4)  # turn the knob

Manim and blur.py never share a GPU context. blur.py runs on its own headless OpenGL context, and manim's default Cairo renderer works on the CPU. The only thing passed between them is a numpy array, so the two can't interfere with each other.

3. Demo: Dual Kawase, step by step

result = blur.dual_kawase(source, levels=4, steps=True, repeat=20)
down, up = result.steps[:4], result.steps[4:]   # 1/2 … 1/16, then back up
result.taps_per_pixel, result.gpu_ms            # numbers for the script

Use steps=True with any blur. For a separable box or Gaussian blur, steps[0] is the horizontal-only pass, which is useful for the linear separation section.

4. Running it

Clips for the video: uv run render

uv run render                                     # every scene in src/examples
uv run render demo_gaussian_sweep                 # every scene in one file
uv run render demo_dual_kawase:DualKawasePyramid  # one scene
uv run render -q l                                # 480p15 while drafting; default is 1080p60
uv run render --list

src/render.py runs manim itself with caching disabled and a transparent background, then writes media/resolve/<file>_<Scene>.mov as ProRes 4444 with alpha, which free Resolve on Linux can read. Every clip uses that one format. A scene that needs a solid backdrop has to draw one.

Quick previews: manim directly

uv run manim -pql src/examples/demo_gaussian_sweep.py GaussianSweep

5. Input and output

In

  • Code: the scene file. Manim adds the file's folder to sys.path, which is why from sample import test_card works. blur is importable everywhere because uv installs the project.
  • Our photos: source photos and footage live in assets/, which git tracks (media/ is ignored). from sample import photo, then photo() returns sands.jpg, the 1080p skyline crop, as float RGBA ready for blur.
  • Images: ImageMobject("photo.png") or ImageMobject(ndarray). Raster images get blurry when scaled up, so call .set_resampling_algorithm(RESAMPLING_ALGORITHMS["nearest"]) when individual pixels should be visible.
  • Vectors: SVGMobject("diagram.svg"), for example to trace a figure from a source.
  • Text: Text renders system fonts through Pango. Tex/MathTex run your TeX Live install (latex → dvisvgm), so equations can be pasted straight from script.tex.
  • Sound: self.add_sound("tada.wav") lines audio up with the animation, for example the TADA in your box blur section.

Out

media/
  resolve/<file>_<Scene>.mov                 # from uv run render: the clips for Resolve
  manim/                                      # render's own manim output and LaTeX cache
  videos/<file>/<quality>/<Scene>.mp4        # from plain manim previews
  videos/<file>/<quality>/partial_movie_files/  # one clip per play(), cached
  images/<file>/<Scene>.png                   # from -s
  Tex/, texts/                                # rendered LaTeX and text cache

Caching trap: manim skips re-rendering any play() whose hash hasn't changed. That hash covers the mobjects and animation arguments, not the code inside blur.py that an updater calls. uv run render always disables the cache. For a plain manim preview after editing blur.py, pass --disable_caching.

Limits

  • The Cairo renderer draws on the CPU. Full-resolution images updated every frame at -qh render slowly but correctly, so keep demo images moderately sized.
  • There's no live preview: you edit, render and watch. -s and -n keep that loop short.
  • 3Blue1Brown's own manimgl is a separate project with an incompatible API. Tutorials for one often don't work in the other, so check that an example imports from manim import *.
