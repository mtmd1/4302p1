# Presentation

"How to blur images in real time with the Dual Kawase Filter"

by Maxence Morel Dierckx (230017391)

## Settings

- Camera -> More -> Pro Video
- 4K @ 30fps
- Auto FPS off
- High bitrate video on
- HEVC on
- HDR10+ video off
- Video stabilisation off
- White balance fixed e.g. 5500K
- ISO as low as light allows (50-200)
- Shutter 1/60
- Focus manual

Record video on mobile and audio with Razer Seiren X into laptop. Sync with Resolve; select video + audio -> right click -> **Auto Sync Audio** -> **Based on Waveform**. Clap at the start to sync by hand if required.
